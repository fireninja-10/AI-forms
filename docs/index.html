Installation

Mise en ligne en 3 étapes

1

Push le dossier `docs/` dans ton repo GitHub.

2

Active GitHub Pages depuis les paramètres du repo, source `main` puis dossier `docs`.

3

Remplace les liens de téléchargement dans `docs/script.js` par tes vrais fichiers.
